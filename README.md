### What the project does
Working on a Markdown Editor made in C++, a GUI frame-work has not been decided, as of nov 2026.

### Usefulness
I am building it, because I mainly use Obsidian sadly Obsidian does not have the functionality to see where a page ends when exporting to pdf. This aims to solve that issue. A place where you can bring your markdown file and edit/export it according to PDF standards.
